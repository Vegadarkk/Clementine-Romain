Données géographiques utilisées par `build-map.mjs` :

- `dep-73.geojson`, `dep-74.geojson` : contours des départements (github.com/gregoiredavid/france-geojson, Licence Ouverte / IGN).
- `lac-annecy.geojson`, `lac-bourget.geojson` : contours des lacs (© contributeurs OpenStreetMap, ODbL, via Nominatim).
- `route-hery-saint-offenge.geojson` : itinéraire routier Héry-sur-Alby → Château de Saint-Offenge (OSRM, © contributeurs OpenStreetMap).
- Contour de la France et pays voisins : paquet npm `world-atlas` (Natural Earth, domaine public).
